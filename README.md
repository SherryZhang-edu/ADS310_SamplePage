# Fertility Rates Teaching Source Page

This is a GitHub Pages ready static website for Assignment 1.

## Purpose

The page gives students a short teaching source based on Our World in Data's article, "The global decline of the fertility rate." Students should transform the page into a 2-3 page LaTeX or Overleaf mini report.

Assignment 1 focuses on:

- academic formatting in LaTeX
- presenting provided data in a table
- creating one simple figure
- writing basic observations
- using an equation or notation
- citing sources properly


## Files

- `index.html`: main webpage
- `styles.css`: page styling
- `assets/fertility-hero.jpg`: optional hero image path
